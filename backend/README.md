# RiskGuard: AI-Powered College Dropout Prediction & Support System

**RiskGuard** is a sophisticated, full-stack predictive analytics platform designed to solve one of the most pressing challenges in higher education: student attrition. By combining the agility of modern web frameworks with the analytical power of Python-based machine learning and Generative AI, RiskGuard provides academic counselors with a "Neural Mission Control" for student success.

### 🧩 The Problem & Choice
Every year, thousands of students drop out of college due to academic, financial, or personal struggles that go unnoticed until it is too late. Most existing solutions are reactive, relying on manual reports. RiskGuard was chosen as a project to transform this paradigm from **reactive** to **predictive**. By monitoring real-time indicators like attendance fluctuations, GPA dips, and qualitative behavioral shifts, the system identifies at-risk individuals weeks before they reach a critical threshold.

### 🛠️ Core Technology & Innovation
The system utilizes a high-performance hybrid architecture:
- **Backend (FastAPI & SQL)**: A Python-based API layer manages complex risk scoring algorithms and persistent SQL storage via SQLAlchemy.
- **AI Engine (Groq & Mixtral)**: Integrates state-of-the-art LLMs to generate "human-like" clinical observations, translating raw data into actionable counselor insights.
- **Frontend (React 19 & Tailwind v4)**: A premium, glassmorphism-inspired UI provides a seamless "Single Source of Truth" for student profiles.

### ✨ Key Features
- **Smart Risk Scoring**: A weighted algorithm (Attendance 40%, GPA 40%, Behavior 20%) that triggers automated alerts.
- **Longitudinal Tracking**: Visualizes risk trends over a 6-month period to identify improvement or decline.
- **Intervention Pipeline**: A Kanban-style board for managing the lifecycle of counselor-student support sessions.

RiskGuard isn't just a dashboard; it’s a proactive lifeline that ensures no student falls through the cracks of the educational system.
